# FOSI — Football Opposition Scouting Intelligence

FOSI is an on-demand football opposition scouting platform.

## Philosophy

FOSI does not try to permanently ingest every event from every team in every competition. It keeps a lightweight competition/team catalogue and performs deep scouting only for teams selected by the user.

**Select → Collect → Analyse → Understand → Prepare**

## Initial target

- Competition: Poland — Ekstraklasa
- Team: Pogoń Szczecin
- Architecture: reusable for any supported competition/team

## Roadmap

1. Foundation and data model
2. On-demand collectors and incremental cache
3. Team/player/event analytics
4. Spatial and tactical visualisations
5. Intelligence: strengths, weaknesses, threats and evidence scores
6. Video evidence links
7. Matchup and match plan
8. PDF reports
9. Automated GitHub Actions updates and deployment
